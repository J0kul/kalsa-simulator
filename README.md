# Kalsa Simulator

An absurd open-world game in the streets of Palermo: walk, ride a Vespa, drive a Lapa, race at the Kalsa Grand Prix and cause trouble with your friends.

**Play:** open the site and press Start. Anyone who opens the same link at the same time is in the same city — no account needed.

- Keyboard: WASD move · Shift run · E get in · Space jump · F hit · T talk · M map · R race (at the circuit) · Esc menu
- Controllers work too (left stick move, right stick look, RT/LT drive, A get in, X hit)
- Phones and tablets get on-screen controls

Multiplayer runs on Supabase Realtime (broadcast and presence only; nothing is stored).
